# Token efficiency (mandatory)

- Prefer short answers and small diffs. Do not narrate every step.
- Do not dump large files, whole schemas, or long command logs into the chat.
- Do not re-explore the repo when the path is known (`backend/`, `frontend/`, `migrations/`, `CLAUDE.md`).
- Do not open unrelated files "for context". Read only what the task needs.
- Do not rewrite working code, regenerate GIS/ML artifacts, or run broad cleaners unless asked.
- Do not add markdown docs, README churn, or comments unless asked.
- Prefer one targeted tool/command batch over repeated speculative searches.
- If blocked, ask one precise question — do not guess with long alternative essays.
- Never paste secrets repeatedly; point to `credentials.json` once when needed.
