# Survey km vs map coverage

When setting or reviewing **daily km targets**, keep the target **slightly below** the real-world distance you expect crews to cover.

Some road segments are **missing from the map index** (incomplete OSM / GIS coverage). Those gaps are **not counted** in assigned km, so a target that matches “true” road length can still leave crews short of finishing the visible network — or push them past the intended area when the map under-represents local roads.

Prefer a conservative daily km (and use Survey Admin **road focus** NH → SH → MDR → Local) so generation stays aligned with what the map can show.
